# Minecraft Launcher

Кастомный лаунчер Minecraft для macOS и Windows. Пиратский (offline) режим, менеджер модов, кастомизируемый интерфейс из блоков и встроенные обновления
![Главное меню](screenshots/screanchot-main-menu.png)

## Возможности

- **Пиратский режим** — вход без лицензии Mojang, играй под любым ником
- **Все загрузчики** — Vanilla, Fabric, Forge, Quilt, NeoForge
- **Менеджер контента** — установка модов, текстурпаков, шейдеров и модпаков прямо из Modrinth
- **Блочный интерфейс** — собери свой дашборд из перетаскиваемых блоков: играть, версия, ник, память, сервер, статистика
- **Классический режим** — привычный вид лаунчера, если блоки не нужны
- **Профили** — несколько изолированных сборок со своими мирами, модами и настройками
- **Серверы** — список серверов с онлайн-статусом и быстрым подключением
- **Проекты** — сохраняй идеи построек с фото и категориями
- **Достижения** — система ачивок в стиле Minecraft
- **Темы и панорамы** — акцентные цвета, фоновые панорамы, свои собственные темы
- **Поддержка старых версий на Apple Silicon** — автоматический фикс LWJGL для 1.13–1.18 и запуск 1.12 через Rosetta
- **Авто-обновления** — лаунчер сам сообщает о новой версии

## Установка

### macOS
1. Скачай `MinecraftLauncher-mac.zip` из [последнего релиза](../../releases/latest)
2. Распакуй и перенеси `Minecraft Launcher.app` в «Программы»
3. При первом запуске: правый клик по приложению → **Открыть** (обход Gatekeeper для неподписанного приложения)

### Windows
1. Скачай `MinecraftLauncher-win.zip` из [последнего релиза](../../releases/latest)
2. Распакуй и запусти `MinecraftLauncher.exe`

## Требования

- Установленная **Java** (17+ для современных версий, 21 для 1.20.5+)
- macOS 11+ или Windows 10+

## Данные

Профили, миры и настройки хранятся отдельно от приложения:
- **macOS:** `~/Library/Application Support/MCLauncher/`
- **Windows:** `%APPDATA%\MCLauncher\`

Обновление лаунчера не затрагивает эти данные — профили сохраняются.

## Технологии

Python + PyWebView, HTML/CSS/JS, [minecraft-launcher-lib](https://gitlab.com/JakobDev/minecraft-launcher-lib), [Modrinth API](https://docs.modrinth.com/).
